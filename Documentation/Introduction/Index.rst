============
Introduction
============

Spark Academics is a core extension for university websites built on TYPO3. It replaces generic page-based content management with structured domain models tailored for academic needs.

Key Features
============

* **Structured Data**: Distinct entities for Staff, Projects, and Curriculum.
* **CERIF Compliance**: Data model alignment with Common European Research Information Format.
* **Interconnected**: Automatically links People to Projects, Courses, and Departments.
* **Localization**: Advanced handling of shared data across languages (e.g., dates and relations are defined once and inherited).

Target Audience
===============

This extension is intended for:

* **Administrators**: To manage organizational structure and user permissions.
* **Academic Staff**: To update their profiles, publications, and project information.
* **Student Services**: To manage course catalogs and study programs.
